# Релиз v1.0 — «Домашние занятия»

Дата: 2026-10-20. Тег: v1.0. Коммит: 00a46da.

## Что это
Локальное веб-приложение для занятий родителя с ребёнком 3–4 лет.
Модуль m01-start-3-4: 12 уроков, сцены, персонаж Luntic, прогресс, офлайн.

## Как развернуть (кратко)
1. `npm ci && npm run build` → `app/dist/`.
2. Скопировать содержимое `dist/` в OSP (`domains/<домен>/` или `local/<папка>/`).
3. Открыть `http://<домен>/`. Подробности — README, раздел «Развёртывание в Open Server Panel (OSP)».

## Как пользоваться
- Главная → «Добавить модуль» → выбрать `m01-start-3-4.zip` (лежит в `dist/modules/`) → «Начать занятие».
- «Мои занятия» — прогресс по 12 урокам (не начат / в процессе / пройден).
- PWA: Chrome → «Установить приложение». Offline: после установки работает без сети.
